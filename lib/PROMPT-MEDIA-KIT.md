# PROMPT PARA O CLAUDE DESIGN — MEDIA KIT @vamonessasp (PDF)

Você é diretor de arte de um media kit comercial. Crie um **media kit em PDF, vertical 1080×1920 (formato story, 8–9 páginas)**, para o perfil **@vamonessasp — "Vamo Nessa São Paulo"**, enviado por WhatsApp a donos e gerentes de **restaurantes, bares e eventos gastronômicos de São Paulo**. Objetivo único do documento: o restaurante responder "vamo nessa" e fechar uma visita + gravação.

## 1. Marca (manter, não reinventar)
- Logo: mão "shaka" 🤙 em traço preto + wordmark **VAMO NESSA** (bold, condensado) com **SÃO PAULO** embaixo em caixa alta fina. Fundo branco. Logo no topo de toda página.
- Títulos de seção em **display caixa alta com contorno vazado (outline)**, ultra-largos, ocupando a largura da página: ALCANCE, CASES, VALORES, CONTATO.
- Paleta: preto #000 / branco #FFF / cinza #6B7280, com **uma cor de acento quente** (laranja-vermelho de comida, ex. #FF4D1C) usada só em números-chave e no botão de CTA.
- Tipografia: display geométrica pesada (ex. Bebas Neue/Anton para títulos) + grotesca limpa para texto (ex. Inter/Manrope). Números grandes em tabular.
- Tom: dois amigos comendo em SP — direto, animado, zero corporativo. Bordão de fechamento: **"E aí, Vamo Nessa?"**
- Fotos: capa com a dupla à mesa cheia de porções e chopp (vou fornecer). Prints de celular com insights reais podem aparecer como "prova", mas os números principais devem ser **tipografia grande**, não print.

## 5. Regras de copy (obrigatórias)
- Números sempre com separador brasileiro (2,96 mi / 32.659) e **com período explícito** ("últimos 30 dias", "últimos 90 dias").
- Nunca escrever "o vídeo trouxe X clientes" ou "gerou X seguidores" — usar "alcançou", "foi visto por", "crescimento observado no período".
- Placeholders entre colchetes devem ficar **visualmente marcados** (fundo amarelo) para eu preencher antes de exportar — não invente valor.
- Português do Brasil, frases curtas, sem jargão de marketing.
